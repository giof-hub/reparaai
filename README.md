# 🛠️ ReparaAí

O **ReparaAí** é uma aplicação desenvolvida com foco na gestão de serviços e atendimento, permitindo organizar solicitações, acompanhar demandas e facilitar a comunicação entre usuários e prestadores de serviço.

O projeto foi desenvolvido como parte de um trabalho acadêmico, com foco em **análise de requisitos, documentação, lógica de programação e organização de sistemas**, simulando um cenário real de desenvolvimento de software.

---

## 📱 Visão Geral

A aplicação tem como objetivo centralizar e organizar solicitações de serviços, proporcionando:

- Melhor controle de demandas
- Agilidade no atendimento
- Organização das informações
- Facilidade de uso para usuários e administradores

---

## 🚀 Funcionalidades

- Cadastro de usuários  
- Abertura e gerenciamento de solicitações de serviço  
- Acompanhamento do status das demandas  
- Organização e controle das informações  
- Interface intuitiva voltada para uso mobile  

---

## 🧰 Tecnologias Utilizadas

- **Frontend / Mobile:** Flutter  
- **Backend:** API REST  
- **Linguagem:** Dart  
- **Controle de Versão:** Git e GitHub  

---

## 📂 Organização do Projeto

O projeto segue uma estrutura organizada, separando responsabilidades por camadas, facilitando a manutenção e evolução do sistema.
